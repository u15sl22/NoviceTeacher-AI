## 实际暴露的问题

- **跨单元提出替换**：审阅概述、目标、重难点时，模型仍针对教学过程提出替换。3 次自动采纳尝试因当前单元没有目标原文而触发候选保护，测试随后拒绝。数据没有被错误覆盖，但用户会感觉建议不属于当前页面。
- **过度判断缺失**：概述单元的建议称课堂小结/板书缺少可操作内容，不能等同于可靠的全篇诊断。
- **拒绝记忆有限**：同一个跨单元问题在多个单元再次出现；当前主要保留同单元拒绝记录，尚不能稳定消除这类跨单元重复。
- **知识支撑仍为空**：12 条检索记录均未取得已核验案例/知识，全部建议仍是未经知识库验证的模型解释，不是专家核验反馈。
- 本次只检查这一份文本，未验证其他教案、DOC/PDF 上传、教学事实整体准确性或教师真实使用满意度。
